# 人工报价维护路径（设计已确定，Provider 待 T05 实现）

适用前提：项目没有已确认可用的价格 API。管理员导入真实供应商文件或人工记录，审核后发布；不登录用户电商账号，不用个人 cookie，不承诺实时全网比价。

## 录入与发布

1. 登记来源：允许使用/展示的证据、商家、原链接或授权文件定位、地区及资料期限。未确认许可保持待审。
2. 匹配精确 SKU：料号/地区/配置/revision；商家 listing 不等同厂商 SKU。无法确定则不参与推荐。
3. 填入整数分价格、币种、数量口径、运费、是否含税、未含税额（如适用）、成色、优惠资格、库存、观察与到期时间。
4. dry-run 验证类型、有效期、身份、重复记录与费用缺口；只预览，不改发布版本。
5. 管理员独立复核关键字段和权限，事务发布 dataset_version；保存审核记录和报价快照。
6. 修价生成新快照；重新核价产生新推荐 revision，不能覆盖历史报价。默认最长 24h 或来源/活动更早截止，不能续写观察时间伪装新鲜。

## 必须明确的错误与未知状态

| 输入情况 | 处理 |
|---|---|
| 未知单价/运费/应付税费 | 相应字段 null，保留缺失理由；总价未知不能 budget_satisfied=true |
| 无运费 | 只有确认证据表明免运才填 0；不是空白默认 0 |
| 会员/券资格不明 | 不扣优惠；没有无条件报价则保持待核实 |
| 库存不明或过期 | 分别显示 unknown / 历史报价，不能标有货或当前预算达成 |
| 缺观察时间、未来观察时间、到期≤观察 | 拒绝发布，不猜采集时间 |
| SKU 未匹配/来源未许可/未审核 | 留在 staging，不污染已发布目录 |
| 同一来源+listing+观察时间+内容重试 | 幂等；不同内容冲突进入复核 |
| synthetic / 模板 | 生产导入拒绝；测试只能使用隔离 TEST-* 夹具 |
