- 新增受会话保护的 `POST /api/v1/agent/preview`。它只读取一个已保存画像 revision，并返回结构化运行状态和工具观察；当前 `llm_provider=disabled` 明确返回 `MODEL_DISABLED`，不伪造自然语言结果。
- 工具白名单只包含目录、事实、报价、笔记本排序、PC 求解和兼容性检查。模型无任意 SQL、shell、URL、导入发布、快照写入或预算覆盖能力；PC/笔记本工具始终从已保存画像取硬约束。
- Harness 固定 4 个决策回合、8 次工具调用和 45 秒总预算；同一运行的规范化读取调用去重，观察转换为有界 JSON。运行时产品 Skills 仅从仓库受信目录提供流程提示。
- 新增 0005_recommendation_snapshots 迁移、不可变快照 lineage 与幂等键记录。创建/修订由服务端重跑 PC 或笔记本确定性求解器，客户端不能提交自定义价格、兼容性或结果。
- 新增受会话保护的创建、读取、修订、比较和导出接口。每个快照保存求解时的数据版本、输入、结果与报价到期时间；读取按保存到期时间标记报价为 current、historical 或 unknown，历史不会被重新核价覆盖。
- 同会话、同路径、同 Idempotency-Key 的重试返回原快照；内容不同返回 409。跨会话读取、修订、比较和导出均返回不可见。
- 新增受会话保护的 `POST /api/v1/recommendations/pc`。它从当前发布目录读精确 SKU 和完整当前报价，先按预算下界剪枝，再执行兼容性验证；不调用 LLM，也不声称全市场最优。
- 搜索参数固定为每槽最多 20 个候选、束宽 100、5 秒预算。响应记录搜索状态、已探索数、已剪枝数、候选池版本，且始终标记 `optimality_proven=false`；资源耗尽和当前搜索范围无解使用不同状态。
- 锁定 SKU 必须保留并计入新增采购预算；已有 SKU 必须保留但不计采购成本。只有金额、运费和必要税费完整的当前无条件新品报价可用于组合。
- 新增受会话保护的笔记本排序接口。预算、地区、禁用品牌、重量和内存是硬过滤；未知硬字段不作为满足。
- 评分固定为 laptop-score-v1。续航、屏幕和应用性能缺失时返回分数区间与证据覆盖，不填充性能数据。
- 新增 C004—C012 的冻结事实检查，覆盖外形、GPU 长度、散热器 socket、电源功率与 PCIe 连接器、存储协议、无独显输出、明确硬需求和清单完整性。
- 聚合仅在 12 条规则全部通过或非阻断 warning 时返回 validated；任一 blocking unknown 返回 needs_verification，任一 fail 返回 incompatible。
- 新增受会话保护的 `POST /api/v1/compatibility/check`。它只读取当前发布的冻结规格事实，并返回事实 ID、规则版本、状态和可审查细节。
- C001 检查 socket；C002 要求精确主板 revision 的 CPU 支持条目和可比较 BIOS；C003 检查内存代际、套装条数、插槽与 CPU/主板容量上限。缺少事实返回 unknown，明确冲突返回 fail。
- C004—C012 在报告中明确列为未执行；所以没有明确失败时总状态仍为 needs_verification，不会提前声明 validated。
- 新增公开只读目录、精确 SKU 详情、规格证据引用、人工报价快照查询和总价计算 API。查询始终从当前发布指针对应的冻结版本读取，开发/生产只读取真实命名空间；测试合成版本只在 test_* 数据库可见。
- 商品详情仅返回已核验 SKU、当前有效且已选择的规格事实，以及具备公开展示许可的来源文档引用。报价只接受当前性、地区、库存、新品和无条件资格均满足的人工快照；不满足条件或费用未知时，总价为 null，不能声称预算通过。
- 前端新增 `/catalog` 目录和 `/catalog/[skuId]` 详情页。空库明确显示“尚无可公开的商品”，没有填充虚构目录；首页增加目录入口。
- 新增受控 manual-v1 人工导入服务、管理员 API 与 CLI，依次执行预览、暂存、审核和发布。HTTP/CLI 复用同一领域服务；没有任意 SQL、shell 或 URL 抓取入口。
- 0004_imports 新增任务快照、数据版本、双命名空间当前指针、规范事实投影、outbox 与通知表。发布用单个 PG 事务：重验、追加记录、冻结版本、事实选择、切换指针与写 outbox 同成同败。
