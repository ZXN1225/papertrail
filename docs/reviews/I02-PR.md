# I02：匿名需求保存、版本历史与会话隔离

此前首页只能编辑页面草稿，刷新后丢失。本轮将三入口接到真实匿名会话与画像服务：首次保存签发安全 cookie，24 小时内刷新恢复；修改追加 revision；另一标签页提交旧版本返回 409 并保留本地编辑供用户处理。新需求和删除会撤销旧身份并级联清除画像历史。

## 关键改动

- 新迁移 0002_sessions；会话内单画像、不可覆盖 revision；预算严格整数分、字段来源、设备切换清理。
- HttpOnly/SameSite/生产 Secure + __Host-、HMAC 签名/摘要、Origin/CSRF/JSON/请求体限制、PG 原子共享限流；配置的 Redis 故障拒绝会话操作。
- 路由共用领域服务，Next 仅桥接固定方法/路径；错误不回显输入或连接凭据。OpenAPI 与生成类型同步。
- 首页保存/恢复/多用途/费用范围/排除品牌、冲突读取、新需求/删除；保留数据未准备好提示。
- 独立 E2E 服务只用 test_* 数据库和 3001/8001，避免测试修改用户预览数据；过期清理命令与运行文档齐全。

## 验证

本机真实 PostgreSQL：30 项后端、15 项浏览器流程通过（375/768/1440）。检查覆盖严格金额、身份/Origin/CSRF、跨会话 404、历史、模式切换、并发、过期/删除、限流与故障。截图已检查。最终 CI/格式/类型/构建/审计结果见 PR 检查与 docs/PROGRESS.md；不以 workflow 文件存在冒充通过。

测试使用 synthetic=true 的 TEST-I02 场景，未导入商品或报价。本机无 Redis 成功连接验证，完整 PG/Redis 由 CI 实测。
