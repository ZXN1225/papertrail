# T03 流程演示结果

数据：tools/synthetic_import.py 生成的 TEST-T03 样例；synthetic=true。不是实际电脑、实际商家或真实报价。以下行为已由真实 PostgreSQL 上的测试及管理员 HTTP/CLI 流程验证。

| 操作 | 可观察结果 |
|---|---|
| 预览样例 | 12 条规范记录标为 add；数据库仍无商品/任务/版本写入 |
| 暂存两次相同文件 | 返回相同任务 ID；目录仍为空 |
| 未审核就发布 | REVIEW_REQUIRED，拒绝 |
| 管理员批准并发布 | 生成一个测试数据版本、一条事实投影、一条 outbox 事件；审核者来自认证配置 |
| 同一任务再次发布 | 返回原版本，无重复记录或事件 |
| 添加数值 8 与 12 的冲突事实 | 预览 FACT_CONFLICT；未选事实拒绝批准；明确选择 12 后投影为 12，原声明 8 仍在 |
| 将报价改成负数/浮点，或给事实填错单位/证据 | 标出错误行；不能批准，已发布版本不变 |
| 发布在切换指针后发生测试故障 | 目录、版本、指针、事件全部回滚；原任务仍 approved，可重试 |
| 两个批次同时以同一父版本发布 | 一个成功，另一个 DATA_VERSION_CHANGED；没有半批版本 |
| 通知消费失败 | 保留 pending、记录错误码并退避；重试成功后只有一条通知记录 |
| 普通用户或陌生网页访问管理操作 | 未授权/跨来源拒绝，不接受普通会话 cookie |

测试金额为 123456 分，仅用于整数精度验证。样例报价时间固定为 2026-01-01—2026-01-02，所以在当前时间运行预览会看到 HISTORICAL_OFFER 警告，这是正常且必须保留的行为。

目前交付入口是后端 `/docs` 和 CLI，管理网页在 T15。开发预览的管理员认证默认关闭，且不接受 synthetic 样例；完整流程由自动测试在一次性 test_* 数据库验证。
