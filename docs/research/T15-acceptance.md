# T15 验收：产品交互与 Agent 运行入口

## 验收目标

- PC、笔记本与单零件三种模式均从同一份保存画像驱动，用户可修改预算、用途和模式特有约束。
- 只有保存成功的画像版本可启动核对；运行请求携带该画像 ID/revision，不把未保存表单内容当作结论依据。
- 页面展示运行状态、已验证摘要、警告和可公开事件摘要。默认模型未配置或资料为空时，明确显示无候选，不虚构商品卡片。
- 前端 API 代理仅放行固定的 Agent 会话、运行、SSE 和取消路径，不接收任意 URL 或主机。
- 375、768、1440 三种视口下真实 API 驱动的保存和运行流程可操作，键盘与空/错误状态保持可读。

## 交付范围

- 首页保留三种需求模式，并在保存需求后加入“根据保存的需求核对”面板。
- 面板创建受会话保护的 Agent 对话，运行后读取 SSE 回放并展示经过后端契约验证的摘要。当前同步 Provider 会立即完成；取消按钮仅在 queued/running 时出现。
- 目录、推荐或 Agent 没有真实已发布数据时，继续展示诚实的空状态。管理员导入/审核仍须服务端管理员授权，未在普通用户页面伪造管理入口。

- 后端与根目录最终检查另在本阶段提交前执行；真实目录、报价、模型服务和管理员凭据仍未配置。
