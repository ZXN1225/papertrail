# T20 检索与 Agent 策略评测集验收

更新：2026-09-22。构建 24 条检索相关性场景和 12 条工具契约场景；全部数据、商品、字段和相关性标签均为 synthetic TEST fixtures。

## 验收条件

1. 检索语料/查询/标签都有唯一 TEST 标识，所有相关性引用指向存在文档；至少 5 个主题桶。
2. 同一冻结语料对比 overlap、BM25 和 RRF(overlap+BM25)，报告总体与分桶 Hit@k、MRR@k、NDCG@k、均值/P95 延迟、数据集哈希、环境和限制。
3. Agent 策略报告只验证服务端工具名/参数契约；覆盖允许工具、任意 URL/SQL/shell 拒绝、参数越界、无效地区和客户端不能覆盖 PC/笔记本硬约束。
4. 不调用模型、商城 API、真实数据库或有副作用的工具。
5. 小型合成结果不得描述为生产 RAG/Agent 质量、市场正确率或真实服务性能。

## 停止边界

本阶段验证的是离线检索和工具契约。真实目录查询、端到端兼容性结果、多轮 Agent 完成率、SSE 恢复和生产负载必须在单独的隔离数据库与模型配置阶段评估，不能从本报告推断。
