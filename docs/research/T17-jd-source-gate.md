# T17 京东公开页面来源门禁与接入计划

更新：2026-09-21。此记录是来源研究和实施前置，不是商品、报价或抓取结果。

## 结论

用户希望以京东商品页作为中国大陆笔记本和 PC 零件的主要价格/目录线索。京东公开商品页可作为研究候选来源，但当前不能启动自动抓取、保存页面摘录或对外发布其商品/价格数据。

京东现行用户服务协议说明平台服务按其发布的规则执行；京东帮助中心的协议修订公告还列出网站资料受京东或内容提供者权利保护，并包含不得将站内已发布信息再发布或授权其他主体使用的表述。京东商品和价格页面也只是交易要约邀请，实际可购性还取决于下单、地区、资格与库存。

## 允许的下一步

1. 用户取得京东书面授权，或取得明确覆盖“商品/价格读取、保存、对外展示”的开放 API 合同和项目凭据。
2. 将授权范围、允许字段、更新频率、地域、缓存时间、展示/摘录范围登记到来源清单并由审核人批准。
3. 仅为已批准的固定域名、固定接口或固定 URL 模板实现适配器；凭据仅置于服务端密钥配置。
4. 每次采集先进入暂存区，保留 URL、获取时间、页面/响应哈希、精确 SKU、地区、卖家、资格、库存与价格字段；dry-run 审核后才可发布。

## 明确禁止

- 不能把“学习研究”“页面无需登录”或 robots 读取失败当成抓取/再发布许可。
- 不绕过验证码、登录、访问控制、反自动化机制或付费接口。
- 不向 Agent 暴露任意 URL、浏览器自动化、shell 或批量抓取能力。
- 不将京东标题、图片、详情正文、评价或价格直接复制到公开目录；在批准前不产生任何真实 SKU、报价或知识摘录。

## 后续任务 J01（仅在许可证据到位后）

实现 `jd-v1` 受控来源适配器：固定入口、服务端凭据、速率/缓存遵循授权合同、断点续传、原始快照不入 Git、dry-run、字段级许可校验、事务发布和撤销开关。验收应包含授权失效、字段超范围、资格未知、价格过期、SKU 不精确、来源下线和部分批失败的反例。
