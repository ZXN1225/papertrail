# T17 国内商品页来源门禁与接入计划

更新：2026-09-22。此记录是来源研究和实施前置，不是商品、报价或抓取结果。

## 结论

用户希望以京东商品页作为中国大陆笔记本和 PC 零件的主要价格/目录线索，并允许在京东接入困难时考察更易读取的常用平台。结论是：京东与联想官方商城都只能作为研究候选来源；当前不能对任一来源启动自动抓取、保存页面摘录或对外发布商品/价格数据。

京东现行用户服务协议说明平台服务按其发布的规则执行；京东帮助中心的协议修订公告还列出网站资料受京东或内容提供者权利保护，并包含不得将站内已发布信息再发布或授权其他主体使用的表述。京东商品和价格页面也只是交易要约邀请，实际可购性还取决于下单、地区、资格与库存。

| 证据 | 地址 | 观察结果 | 结论 |
|---|---|---|---|
| 用户服务协议 | https://help.jd.com/user/issue/945-4583.html | 2026-01-20 生效版本；规则会随平台更新 | 不能将公开可见视为授权 |
| 协议修订公告 | https://help.jd.com/user/notice/detail-5d60c91bbd8e06f75b5d6160.html | 明示站内资料的权利保护与再发布限制 | `public_display=false`、`excerpt_storage=false` |
| 商品/价格协议说明 | https://help.jd.com/user/issue/965-3892.html | 商品和价格展示是要约邀请 | 价格必须带观察时间、地区、资格和有效期 |
| robots | https://www.jd.com/robots.txt | 本轮工具读取失败，未取得可解释规则 | 不从失败推定允许 |
| 开放接口研究 | https://help.jd.com/oapihelp/question-460.html | API 使用涉及授权取得的商家 Key | 未取得项目授权或凭据，不调用 |

## 替代候选：联想官方商城

联想官方商城的新品和分类页可公开读取精确商品配置与标价，作为“页面字段可访问性”的探测对象比京东更直接，且覆盖笔记本、台式机及部分配件。然而，联想中国法律公告明确说明：网站提供信息不构成任何版权、专利或其他知识产权许可；账户与服务内容的条款也要求未被明确允许的用途不得获取或使用内容。因此它不能作为绕过京东授权问题的替代采集源。

| 证据 | 地址 | 观察结果 | 结论 |
|---|---|---|---|
| 新品目录 | https://shop.lenovo.com.cn/page/newarrival/xpzx.html | 公开页面可定位笔记本和台式机的配置、标价与商品页入口 | 技术可读，不等于可采集/发布 |
| 分类目录 | https://shop.lenovo.com.cn/fenlei/page_pc.html | 公开目录覆盖 PC 分类和商品入口 | 仅可用于字段可访问性研究 |
| 中国法律公告 | https://shop.lenovo.com.cn/investor/html/legal.html | 提供信息不授予版权、专利或其他知识产权许可 | `public_display=false`、`excerpt_storage=false` |
| 账户及服务条款 | https://shop.lenovo.com.cn/page/xs/jyth.html | 未明确允许的内容获取或使用受限 | 未取得书面许可前不启用自动通道 |

联想商城登记为 `lenovo_cn_mall_public_page`，状态为 `technically_readable_pending_written_authorization`。它不是已启用的数据源，也不含任何真实 SKU、价格或规格记录。

## 允许的下一步

1. 为京东或联想商城任一候选来源取得书面授权，或取得明确覆盖“商品/价格读取、保存、对外展示”的当前 API 合同和项目凭据。
2. 将选定来源的授权范围、允许字段、更新频率、地域、缓存时间、展示/摘录范围登记到来源清单并由审核人批准。
3. 仅为已批准的固定域名、固定接口或固定 URL 模板实现适配器；凭据仅置于服务端密钥配置。
4. 每次采集先进入暂存区，保留 URL、获取时间、页面/响应哈希、精确 SKU、地区、卖家、资格、库存与价格字段；dry-run 审核后才可发布。

## 明确禁止

- 不能把“学习研究”“页面无需登录”或 robots 读取失败当成抓取/再发布许可。
- 不绕过验证码、登录、访问控制、反自动化机制或付费接口。
- 不向 Agent 暴露任意 URL、浏览器自动化、shell 或批量抓取能力。
- 不将京东或联想商城的标题、图片、详情正文、评价或价格直接复制到公开目录；在批准前不产生任何真实 SKU、报价或知识摘录。

## 后续任务 J01（仅在许可证据到位后）

在选定并获授权的来源上实现 `jd-v1` 或 `lenovo-mall-v1` 受控适配器：固定入口、服务端凭据、速率/缓存遵循授权合同、断点续传、原始快照不入 Git、dry-run、字段级许可校验、事务发布和撤销开关。验收应包含授权失效、字段超范围、资格未知、价格过期、SKU 不精确、来源下线和部分批失败的反例。
