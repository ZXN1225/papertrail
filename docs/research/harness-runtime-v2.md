# Research runtime v2 — 2026-11-11

生产入口统一为 ResearchRuntime，注入模型的测试也使用同一路径。旧 AgentHarness 保留供历史离线评测，生产不再使用关键词任务路由。

1. 语义计划：模型根据当前问题、账号文档目录、最近原文及持久摘要输出结构化计划。目录明确区分书目来源与本地检索范围；已入库 arXiv 论文属于 library。
2. 执行：后端映射固定工具。账号目录键、来源类型和文档 ID 必须一致。公开检索需要当前请求的引用依据。无任意 URL、SQL 或写操作。
3. 回答：检索结果构成当前轮证据库，模型只引用证据编号；引文和位置由服务器绑定，消除模型重复抄写标识导致的错配。
4. 复核：事实、分析、建议分开；独立模型阶段复核主张。未支持内容移除，缺失来源显式报告，不能伪装完整成功。模型复核不是事实正确性的证明。
5. 记忆：SQLite 迁移 0021 保存研究目标、文档身份和压缩摘要；最近 12 轮原文受 16000 字符窗口约束，长期摘要独立保存。清空对话递增版本并清除摘要；过期执行不能覆盖新状态。历史内容不充当本轮论文证据。
6. UI：提交立即显示用户消息，Enter 发送、Shift+Enter 换行、清空输入。研究任务和摘要可展开查看。

参考公开设计：[Codex harness](https://developers.openai.com/blog/codex-as-a-platform)、[LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence)、[Deep Agents](https://docs.langchain.com/oss/python/deepagents/overview)。不声称掌握 Codex 未公开内部实现。
