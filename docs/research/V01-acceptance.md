# V01 验收范围

用户已确认第一步，授权继续第二步，完成后再次暂停。本轮不搭建 P1 应用、不合并 PR、不申请外部账号或发送授权邮件。

验收按原规格 §9.2 / §18 的“每源至少 5 样本或明确失败证据”：

- 四类来源分别有 URL、实际检查日期、访问方法、字段覆盖和缺口。
- 能读取的来源做小样本人工核对；受访问或权限条件限制时记录具体失败，不绕过、不伪造成功样本。
- 权限、访问、身份、字段完整、发布资格分开；来源报告不作为已审核商品数据导入。
- 价格 API 不可用时确定人工报价的字段、审核、未知/过期和发布条件。
- 核验下一轮运行时支持范围、依赖组合候选和本机环境；锁文件与实际构建留在 I01。
- 运行基础检查和本轮研究记录检查；更新 README、TASKS、PROGRESS，提交增量 PR。

来源通道失败不等于 V01 研究失败，但真实数据发布仍被阻断；后续 T03/T04 的真实样本与适配器验收不能因此免除。
