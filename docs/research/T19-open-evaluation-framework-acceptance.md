# T19 开放数据与检索评测框架验收

更新：2026-09-22。选择 Wikidata CC0 作为开放实体资料候选，选择隔离合成检索金标作为当前可复现评测集；不导入实时商城价格。

## 验收条件

1. Wikidata 来源记录明确其只覆盖开放实体资料，不作为中国实时价格或完整兼容性事实来源。
2. 检索金标集标记 `synthetic=true`，所有文档和 case ID 使用 `TEST-*`，不进入真实目录索引。
3. 评测命令实现 deterministic overlap 与 BM25 两种检索器，输出 Hit@k、MRR@k、NDCG@k 与查询延迟摘要。
4. 指标实现有独立单元测试；报告记录数据集哈希、方法、k、样本量和限制。
5. 不把小型合成集成绩写成真实市场效果、生产 RAG 质量或 Agent 质量。
