## 修订后的实验约束

- 用户另行明确授权**新增最多 USD 2**，用于同一 `gpt-5.6-sol`、同六题、每题一个可评分 trial 的技术性重跑；旧三次失败保留为工程事件，不并入表现数据。
- 每个 worker 最多 **一次**受限 arXiv 源 BM25 检索，工具返回后不再向模型提供工具定义；每个 worker 最多 **两次**模型请求。六题的三臂最多 24 个 worker、48 次模型请求；四个 worker 都使用同一问题、来源范围、模型、最大输出 600 tokens、上下文 120k 字符和相同上界。
- 上一版一次检索可返回多达 8 个 chunk，R1/R4 的指定直接 chunk 原先未在冻结前 8，改进控制流不会将该次漏命中改写成命中。若一次检索证据不足，必须拒答或由 Harness 拒绝无证据回答；不能把拒答记作检索成功。
- 新本地报告仍写在 Git 忽略目录，保留每个 arm 的状态、工具观察、token 与费用估算。若达到新增 USD 2 的下一请求保守上界，就停机并报告完成比例。实际生成答案仍需用户人工逐题审阅后方可计算语义成功率。
- 第 4 次诊断后又在**调用前**修正了工具定义：`source_type` 只可为 `arxiv`、`source_id` 只可为该题冻结 ID、`retrieval_method` 只可为 `bm25`；工具响应仅返回引用核验所需的 excerpt、chunk ID、locator、来源 URL、标题、许可与定位字段，去除重复的 parser/expanded 上下文，保留原 BM25 前 8 顺序。这与执行层白名单一致，避免模型被展示它其实不能调用的方法。第 4 次已记录估算 $0.896874，故新增 USD 2 额度下，下一次运行器额度降低为 **USD 1.10**；`$0.896874 + $1.10 = $1.996874`，未超过新增授权。第 4 次本地报告保留原字节及 SHA，不覆盖。

本次修订的合成 TEST 门禁覆盖“一次检索后关闭工具定义”、跨源拒绝与本地费用/请求数停止条件；修订前的三份报告不删改。项目和远端 GitHub 仍未上传这轮改动。
