# P39：小规模全文 RAG 评测规范

状态：P46 top-10 扩展评分已完成；10 篇许可审核后的全文共 417 个片段，`text-embedding-3-large` 向量覆盖 417/417。共 127 个候选人工评分和两条不可回答性判断，单评审探索性结果。P47 的来源轮转重排反事实检查未改善目标指标；没有更改生产检索策略。

## 目标

为 BM25、Dense 与 Hybrid 建立同语料、同问题、同判断的全文证据检索基线，并控制人工工作量。P39 先冻结评测协议和标注格式；后续基线运行必须使用明确批准的全文。元数据检索评测、合成夹具和模型自评不能代替本评测。

## 最小试点范围与人工预算

- 固定 8 个问题，每桶 2 个：精确术语/词面检索、语义改写、需要多处证据的问题、当前批准语料无法回答的问题。
- 仅使用已人工确认许可、已导入且仍处于批准状态的全文。每个可回答问题应能定位至少一个支持它的全文片段；不可回答问题须确认所问内容在本次冻结语料中没有支持片段。
- 对 8 个问题，分别运行 BM25、Dense、Hybrid，各取 top-2；按片段 ID 去重形成盲化候选池。候选最多 48 个；为确保每个可回答问题至少有一个已知正例，额外加入每题一个经人工定位的支持片段（若尚未在池中），因此片段评分最多 54 项。不得把池外内容解释成不相关。
- 对 2 个不可回答问题各做一次语料内可回答性判断。随机抽取最多 8 个候选片段做第二次独立评分。总片段评分与可回答性判断硬上限为 **64 项**（54 + 2 + 8）；达到上限即停止，不自动扩池或追加标注。
- 候选池实际少于上限时按实际数量记录。除非用户之后明确同意，不扩大查询数、候选数或双评比例。

## 标注内容

每个问题包含稳定 ID、意图桶、问题文本、预期回答范围、答案性（可回答/当前语料不可回答）和相关许可文档 ID。每个候选片段只展示随机 ID、论文标题、章节/字符定位及片段文本；隐藏检索方法、排名和系统分数。

相关性采用 0–3 级：0 不支持问题；1 主题相关但不能直接支撑回答；2 能支持部分回答；3 直接且充分支持问题。对 2/3 分片段同时记录支持的问题要点或字符定位。缺少许可、文档不在冻结语料、片段无法核验时标为无效样本并停止评分，不得用 0 代替。

第二评审独立评最多 8 个候选片段。报告分歧数和逐级一致情况；试点不以小样本一致性声称标注者可靠性，也不强制额外仲裁以免突破 64 项预算。存在分歧的样本在主分析中按较低分计，并附敏感性分析说明。

## 指标与解释边界

- 检索层：Hit@1/2、MRR@2、NDCG@2，按四类问题分桶展示；Recall 仅称为“候选池内 Recall”，不得称为语料级 Recall。
- 不可回答桶仅有 2 个案例，报告逐题结果，不给出稳定的总体拒答率或统计显著性结论。
- 本试点用于找失败模式、验证指标与工作流、决定是否值得扩充；8 个问题和最多 64 项片段评分/可回答性判断只支持探索性结论，不能宣称普遍检索质量提升或模型优劣。
- P39 不评测生成答案的完整性、主张忠实度或 citation precision/recall；这些属于之后的答案层评测，必须与检索层分开。

## P41 探索性基线结果

用户完成 40 条候选评分，分布为 0 分 12 条、1 分 7 条、2 分 11 条、3 分 10 条；所有 2/3 分均填写支持说明。Q07、Q08 均被判断为当前批准语料不可回答，并给出理由。总人工工作量 42 项（40 条评分 + 2 条可回答性判断），没有进行第二评审。

下表为 6 个可回答问题上的宏平均 top-2 指标；相关性阈值为 grade ≥ 2，NDCG 使用 `2^grade - 1` 增益。Recall 只以盲审候选池中人工判为相关的片段为分母。

| 方法   | Hit@1 | Hit@2 | MRR@2 | NDCG@2 | 候选池内 Recall@2 |
| ------ | ----: | ----: | ----: | -----: | ----------------: |
| BM25   | 0.333 | 0.500 | 0.417 |  0.287 |             0.108 |
| Dense  | 0.667 | 1.000 | 0.833 |  0.783 |             0.522 |
| Hybrid | 0.833 | 1.000 | 0.917 |  0.713 |             0.397 |

在本题集里，Hybrid 的 Hit@1/MRR@2 较高，Dense 的 NDCG@2/候选池内 Recall@2 较高；Dense 与 Hybrid 均在六个可回答问题的 top-2 至少命中一个 grade≥2 片段。由于样本小、单评审且候选池由三种方法 top-2 合并并补入最多 6 个支持锚点，这些数字只用于探索和错误定位，不能证明普遍质量提升或统计显著差异。Q07/Q08 各只有一个不可回答案例，不计算总体拒答率。生成报告未采集逐次检索耗时；本评测也不涉及生成忠实度或引用精确率。

按 grade≥2 的 Hit@2 检查失败题，BM25 在 Q01、Q04、Q06 未命中池内相关片段；Dense 和 Hybrid 在六题中均至少命中一个。复杂问题的一个部分支持片段命中仍计作 Hit，因此 Hybrid 的 Hit@2=1.0 不表示每题所需的全部证据都已找齐。此处只定位问题，不据此改动默认检索器或对这 8 题调参。

另做了未预注册的双来源覆盖诊断：Q05/Q06 各要求比较两篇论文，但在三种方法各自 top-2 中，均没有同时包含两篇来源上人工评为 grade≥2 的片段。Q05 每种方法覆盖 1/2 个来源；Q06 的 BM25 为 0/2，Dense 与 Hybrid 各为 1/2。该诊断只有两个问题，依赖当前盲审池和支持来源映射，只用于提出下一步方案：改进多论文问题的证据集合完整性，而不是单纯增加单篇相关片段命中率。

## 冻结与隐私

正式运行前固定许可审查状态、文档版本 SHA-256、chunker 版本、chunk ID、检索器配置、Embedding 模型/维度、问题集版本与评测脚本版本。三种检索方法共用相同文档、chunk、查询与过滤条件；记录调用次数、输入 tokens、耗时和估算费用。Dense/Hybrid 仅在用户已有的显式 provider 配置下运行，不在制定协议时调用外部 Embedding API。

原始全文、片段正文、个人研究问题及逐条标注默认留在本机忽略目录。GitHub 只发布协议、可公开的评测脚本、数据/代码哈希和汇总指标；若公开任何查询或片段，须先确认相应许可和发布权限。测试夹具继续使用 `TEST-*` 与 `synthetic=true`，不能冒充真实质量结果。
