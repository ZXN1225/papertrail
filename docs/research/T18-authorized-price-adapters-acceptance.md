# T18 授权报价适配器基础层验收

更新：2026-09-22。范围是授权 API 的配置门禁、固定来源注册表和申请操作指南；不调用外部 API，不导入真实商品、报价或凭据。

## 验收条件

1. 仅注册明确命名的来源；配置不能接受任意 API 名称、主机或 URL。
2. 默认没有启用来源；缺少来源许可说明、App Key、App Secret 或推广位/站点标识时，来源不得成为可用状态。
3. 配置检查不输出密钥原文，且 `.env.example` 只含空占位符。
4. 当前 `ManualOfferProvider` 和报价计算行为不变；本轮不进行网络请求、页面抓取、自动暂存或自动发布。
5. 提供京东联盟、京东企业采购、淘宝/天猫开放平台、多多进宝和厂商/分销商资料源的申请步骤，并明确每个来源都需以当前合同为准。
6. 单元测试覆盖默认禁用、未知来源、重复来源、缺失凭据和完整的京东联盟配置；静态检查和来源记录检查通过。

## 完成定义

满足以上条件后，用户可将凭据保存在本机/部署环境的 `.env` 或密钥管理服务，并将已签署的许可范围交给审核流程。下一轮才实现已选 API 的固定 HTTP 客户端、限流、响应映射、暂存、dry-run 和人工发布；没有有效合同或凭据时继续使用 `manual-v1`。
