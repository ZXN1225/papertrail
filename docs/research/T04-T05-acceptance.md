# T04/T05 验收（实施前固定）

步骤 07：对当前已发布数据版本提供公开只读目录、精确 SKU 详情、证据可追溯事实、报价快照查询，以及确定性总价函数。T06 兼容性、T08/T09 推荐和管理界面不在本轮。

- 目录只读取当前命名空间指针的冻结版本；开发/生产绝不读取 synthetic，测试环境仅读取 test_* synthetic。没有当前真实版本返回诚实空结果，不能硬编码商品。
- 列表支持 category、region、query、游标/limit；稳定排序按 SKU record_key/id。详情按精确 SKU，不以系列或别名静默合并；未知或未选择的事实不作为满足条件。
- 详情返回当前 canonical 事实、原始值/单位、证据定位、文档哈希/时间/来源与数据版本；来源须具有 public_display。没有公开资料时不泄露待审、原文、内部审核说明或其它版本。
- 报价读取当前数据版本且绑定 SKU、地区、成色、无条件资格、库存、观测/过期时间和数据版本。当前报价同时满足 observed_at、expires_at 与 PRICE_MAX_AGE_SECONDS；历史查询标为 historical，不冒充当前。
- ManualOfferProvider 只从发布快照读取，未接外部 API、网页抓取或实时比价。消费者固定数据版本/报价 ID，不能混不同版本。
- 总价使用整数分：数量 × 基础价 + 每项已知运费 + 未含税费。税已含不重复加；必要费用或价格未知则 total_minor=null，仍返回 known_subtotal_minor/unpriced_items；budget_satisfied 此时为 null。恰等预算为 true，多一分 false。
- 选择报价必须匹配 SKU/地区/有效期/资格/新货库存；过期、未知库存、会员/券/套装或错误报价 ID 不可默认为可获得。输出最早到期时间、价格完整性和每项快照引用。
- 类型/数据库实测：空真实目录、测试/真实隔离、分页、查询、版本切换、证据范围、报价 TTL、税运费、缺价、浮点/负数、预算边界、错误 SKU/offer/版本等反例；原会话/导入和浏览器流程回归。
- 新增只读前端目录页，显示数据版本、空状态、商品/证据/报价时间与缺价状态；无需管理凭据。同步契约、文档、TASKS/PROGRESS，创建独立 PR 后暂停。
