# I01 验收（实施前固定范围）

本轮实现步骤 03，不推进 I02 会话、画像保存或 T02 商品表。原始规格不修改。

- Python 3.12 / Node 24 / pnpm / uv 和前后端依赖固定；uv.lock、pnpm-lock.yaml 入库，CI 使用 frozen 安装。
- FastAPI 具备 live、ready、平台准备状态接口和 OpenAPI；错误不泄漏连接凭据。
- Alembic 从真实 PostgreSQL 空库建立基线版本。I01 只建立迁移版本表，商品/来源业务表在 T02 创建；应用启动不自动迁移。
- ready 校验数据库连通与迁移版本；PG 不可用或迁移未执行返回 503。Redis 配置后须探测，生产必需，开发可显式关闭。
- 生产缺数据库/Redis/会话密钥或使用不安全配置时拒绝启动；管理员写接口和 LLM 接入本轮均未开放。
- 中文首页三个入口、预算/用途草稿、未准备好提示和依赖故障状态；不造商品、不返回推荐。无模型密钥可浏览和编辑草稿。
- Playwright 对真实 API 执行 PC/笔记本/零件入口、空数据/断网状态及 375/768/1440 视口检查。
- Compose 提供固定摘要的 PG/Redis；本机无 Docker/WSL 时以便携 PG 做本地验证，并在 CI 实测完整 PG/Redis 组合，分别报告。
- 测试、类型、构建、OpenAPI 同步、依赖审计、CI 结果和启动指南真实可复现。完成后创建 PR，等待用户确认。
