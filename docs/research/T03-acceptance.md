# T03 验收（实施前固定）

步骤 06：受控人工 JSON 导入、dry-run、暂存、错误/差异预览、管理员审核、原子数据版本与 outbox。T04 公开目录界面和 T05 报价 Provider 不在本轮。

- 写入前严格验证、确定性归一化；精确配置指纹有版本与可复现输入；返回行号/字段/错误码，不回显认证信息或底层 SQL。
- dry-run 不改变目录、任务、版本或 outbox；暂存保留输入快照哈希、规范记录、问题与检查点；同来源/外部批号/内容重复幂等，不同内容必须显式新批号。
- 管理员独立 Bearer 认证，未配置禁用；匿名 cookie 不能访问；审核身份服务端推导；限制请求大小、行数与写频率，浏览器跨来源拒绝。
- 审核绑定批次内容哈希与父数据版本；未知来源权限、SKU 未确认、未审核证据、未解决事实冲突、生产 synthetic 不发布。合成发布只允许 test_* 测试库，真实与测试指针隔离。
- 发布事务中重验，目录记录追加不覆盖；版本快照/规范事实投影/当前指针/outbox 同成同败。并发旧父版本拒绝；重复发布返回原版本，故障后可重试。
- outbox 有租约/重试与幂等消费记录；同步人工导入的 resume 返回持久化检查点，不宣称已实现外部抓取。
- 迁移 0004 与契约同步，真实 PG 验证升级/回退及上述反例，原有需求与浏览器流程回归。
- 提供 CLI 操作手册、JSON 规范与可复现 TEST 示例；本轮不擅自授权真实资料。真实样本端到端另列验收，D01—D03 未解除时保持 blocked。
- 更新 TASKS/PROGRESS，推送独立 PR，不合并；完成后等待确认。
