# T02 验收（实施前固定）

步骤 05：SKU、来源、文档、证据、事实、商家、listing、报价的数据模型；不推进 T03 导入/审核/发布，不添加真实目录或模型。

- 自包含 Alembic 0003 从 I02 升级；真实 PG 空库、重复升级、降回 I02/重新升级通过；已有会话/画像历史保留。
- 品牌/系列/SKU 分离；规范名称、已确认精确身份唯一；未知料号/revision 保持待确认，不误合并；不同地区/配置不能串 SKU。
- 来源权限默认未知；文档记录哈希/时间/解析版本；证据有定位及 SKU 范围。事实/报价通过外键绑定对应 SKU 的证据，不接受别的 SKU 或断链引用。
- 属性类型/单位/类别与事实匹配；缺失为 null + 原因，多条冲突声明可以并存；审核记录不等于已发布事实。
- 金额 BIGINT 整数分、非负、缺价 null；报价挂已匹配 listing，包含税运费、资格、成色、库存和有效区间，不将未知当零。不实现 Provider/总价/当前报价选择。
- synthetic=true 记录使用 TEST-* 标识；复合外键阻止合成与非合成记录混用；测试仅在 test_* 数据库，不建立发布索引。
- 强类型 Pydantic 记录契约、SQLAlchemy 模型、数据库 Check/Unique/FK 双层校验；OpenAPI 描述记录 Schema，但不宣称存在未实现的导入/目录路由。
- 数据字典和关系图可审查；本机/CI 实测有效链及重复身份、负数/浮点输入、错误类型/单位、时间区间、错 SKU 证据、无来源、隔离、迁移回归等反例。
- 保留三入口与会话体验，平台继续显示数据准备中；更新 TASKS/PROGRESS，创建增量 PR，完成后暂停。
