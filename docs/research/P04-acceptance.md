# P04 验收记录：元数据快照与论文目录

日期：2026-09-23。分支：`codex/paper-research-agent`。

## 验收条件

- SQLite 版本化迁移可重复；本地 DB 文件不进入 Git。
- 每次 OpenAlex 导入产生可追溯快照：查询/分页参数、source/license、采集时间、总匹配数、接收数与内容哈希；认证信息不持久化。
- 稳定 OpenAlex ID 是作品主键。相同内容重复导入保持版本幂等；改变字段追加不可变版本，并能从旧快照追溯。
- 固定分页单次 CLI 导入最多 25 条；真实烟测最多 10 条，不下载全文。
- 提供只读本地目录、单篇详情和导入快照接口；空库不制造示例记录。
- 摘要由 OpenAlex 倒排索引确定性重建；缺失或超界数据清晰标记，不推测内容。
- 自动化测试覆盖成功/重复/变更/故障回滚、字段白名单、摘要、分页和 lineage。
- 完成后只在本机 SQLite 导入一页小样本；只报告计数、ID/哈希摘要，不向 Git 添加数据库或真实原始采集文件。
- 旧电脑代码与 GitHub 分支在通用代码迁移完成前保留。

## 实施前许可核验

OpenAlex 当前官方说明其数据以 CC0 公共领域许可发布；本阶段只保存 Works API 的元数据/摘要字段，不下载或复制论文全文。具体项目字段与来源 URL 仍作为 lineage 保存。
