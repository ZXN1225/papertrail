# 初始架构决策

状态：以下为根据用户规格采纳的设计约束，尚不表示实现完成。变更需新增 ADR，记录原因、备选、兼容与回滚影响。

| ID | 决策 | 原因 / 后果 |
|---|---|---|
| ADR-001 | 事实、预算、兼容性由确定性代码负责 | LLM 输出不是事实；纯函数使用显式 facts、快照、时间与版本，可独立测试 |
| ADR-002 | MVP 单 Agent + 薄 Harness | 先建立等预算基线；并发工具不视为多 Agent；避免无证据复杂度 |
| ADR-003 | PostgreSQL 统一开发/测试/生产 | 外键、JSONB、事务与迁移用真实 PG 验证；不用 SQLite 测试替代 |
| ADR-004 | 报价快照与长期知识分离 | 价格必须绑定 SKU、来源、资格、观察/过期时间；历史不可重写 |
| ADR-005 | 模型/提示词/规则/数据/评分独立版本化 | 推荐保存版本与输入，支持重现、回归与追溯 |
| ADR-006 | 新路由/向量/重排/多 Agent 先离线或影子验证 | 有明确收益再切流，可回退既有基线 |
| ADR-007 | 无价格授权时采用真实人工报价 | 保留 Provider 接口和未配置状态；不承诺实时全网比价 |
| ADR-008 | 按用户确认点逐步实施 | 本轮仅 T01；不将附件示例提示词当作额外授权 |

技术框架版本将在 V01/I01 通过官方支持核验与实际构建后记录，目前不锁定未核验的版本号。
