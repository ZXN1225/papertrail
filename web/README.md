# 前端 · I02

Next.js/React/TypeScript/Tailwind 与锁文件沿用 I01。命令见 [开发指南](../docs/development.md)，行为见 [会话设计](../docs/sessions.md)。

三入口现可保存需求、刷新恢复，支持多用途、费用范围、排除品牌和设备专属条件。未保存编辑留在内存；已保存内容固定 24 小时有效。冲突保留本地编辑并提示读取最新版本，新需求/删除经用户点击确认后清除服务端旧内容；不内置真实商品或伪造推荐。

lib/api/schema.d.ts 从后端契约生成，不手改。Next 白名单桥接固定会话/画像方法和状态 GET，API_BASE_URL 为服务端配置，不接受浏览器输入的 host/URL。cookie 为 HttpOnly，CSRF 只在页面内存中，数据库/模型凭据不进入浏览器。

E2E 使用独立 test_* 数据库及 3001/8001 端口，15 项流程覆盖 375/768/1440 三个宽度、保存恢复、跨标签冲突、删除/隔离、故障和键盘；不以此代替 P6/P7 全可访问性、安全和负载验收。商品列表/推荐/对话/后台仍在后续阶段实施。
