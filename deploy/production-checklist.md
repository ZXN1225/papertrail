# 生产发布前置清单

- [ ] 已获得真实 SKU、规格、报价和公开展示所需的来源许可；D01—D03 已解除。
- [ ] 至少 120 条人工独立标注金标及保留集完成，满足规格 §16.3 的硬约束、预算、证据与价格正确性门槛。
- [ ] 已配置并单独评估模型、提示词、工具版本、成本与超时；CI 不调用付费模型。
- [ ] 已提供目标服务器、域名、TLS、密钥系统、生产 PostgreSQL/Redis、管理员身份与数据保留策略。
- [ ] 已在隔离环境完成备份恢复演练，并记录实际 RPO/RTO。
- [ ] 已运行锁定依赖、迁移、后端/前端/E2E、依赖审计和合成冒烟检查。
- [ ] 已配置代理关闭 SSE 缓冲、限制跨域来源、只开放 HTTPS，并确认数据库/Redis 不暴露公网端口。

未全部满足时只能交付受限开发预览，不能宣布生产可用。
