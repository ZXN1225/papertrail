# 备份与恢复演练操作手册

此手册用于有独立预发布环境、经批准的数据库凭据和明确恢复窗口时执行。不得对开发库、用户本机工作库或生产环境试运行删除/还原命令。

## 前置条件

- 目标库是隔离环境，数据库名以 `test_` 或批准的预发布命名空间开头。
- 已记录应用提交、Alembic head、数据版本与执行人；备份路径为受控、加密的位置，不提交仓库。
- 已取得数据源展示和恢复所需的许可。备份不绕过来源授权。

## 演练步骤

1. 在切换前执行 `/api/v1/health/ready`，保存脱敏结果和当前 `alembic_version`。
2. 使用 PostgreSQL `pg_dump --format=custom --no-owner` 备份指定隔离库；记录文件 SHA-256，不在日志输出连接串或密码。
3. 新建空的隔离恢复库，执行 `pg_restore --clean --if-exists`，再以应用锁定依赖运行 `alembic upgrade head`。
4. 启动 API 后验证 ready、会话隔离、空目录和两条合成浏览器流程。检查恢复库中的数据版本、推荐快照和可公开证据引用一致。
5. 记录实际 RPO/RTO、失败点和恢复证据。演练结束后按环境保留策略清理恢复库与临时备份。

## 回滚原则

应用可以回滚到兼容的旧版本；数据库迁移不能因应用回滚自动降级。任何破坏性迁移必须在单独变更中有经测试的恢复计划。当前迁移均按扩展优先处理，但这不构成已完成的生产恢复演练。
